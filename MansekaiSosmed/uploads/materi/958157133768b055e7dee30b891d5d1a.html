Materi Lengkap: HTML, CSS, & JavaScript

Panduan Menggabungkan Ketiga Pilar Web dalam Satu Berkas Internal (Single-File)

1. Pendahuluan: Tiga Pilar Web

Dalam pembuatan halaman web modern, terdapat tiga teknologi utama yang saling melengkapi ibarat fondasi, cat/dekorasi, dan sistem kelistrikan pada sebuah rumah:

  • HTML (HyperText Markup Language): Berfungsi sebagai struktur dan kerangka dasar halaman web (teks, gambar, tombol, formulir).
  • CSS (Cascading Style Sheets): Berfungsi untuk mempercantik tampilan, mengatur tata letak (layout), warna, font, dan responsivitas.
  • JavaScript (JS): Berfungsi untuk memberikan interaktivitas, logika, animasi dinamis, serta manipulasi elemen web tanpa perlu memuat ulang halaman.

2. Apa itu "Internal HTML"?

Biasanya, pengembang memisahkan file HTML, file CSS (.css), dan file JavaScript (.js). Namun, pendekatan Internal berarti kita menempatkan kode CSS dan JavaScript langsung di dalam satu dokumen HTML yang sama:

  • CSS diletakkan di dalam tag <style> di bagian <head>.
  • JavaScript diletakkan di dalam tag <script> biasanya di bagian bawah sebelum </body>.

Pendekatan ini sangat ideal untuk pembelajaran, prototipe cepat, atau pembuatan halaman portofolio/landing page mini mandiri.

3. Struktur Kerangka Dasar

Berikut adalah struktur dasar penulisan HTML yang menggabungkan CSS dan JavaScript secara internal:

<!-- Struktur Dasar Internal HTML, CSS, JS -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Web</title>
    
    /* CSS INTERNAL: Diletakkan di dalam tag <style> */
    <style>
        body { background-color: #f4f4f4; font-family: sans-serif; }
        h1 { color: #2563eb; }
    </style>
</head>
<body>

    <!-- KONTEN HTML -->
    <h1>Halo Dunia!</h1>
    <button id="myBtn">Klik Saya</button>

    /* JAVASCRIPT INTERNAL: Diletakkan di dalam tag <script> */
    <script>
        document.getElementById('myBtn').addEventListener('click', function() {
            alert('Tombol berhasil diklik!');
        });
    </script>

</body>
</html>

4. Penjelasan Langkah-demi-Langkah

  1. HTML (<div>, <p>, <button>): Membuat elemen visual yang dapat dilihat dan berinteraksi dengan pengguna.
  2. CSS (<style>): Mengatur agar kotak demo memiliki latar belakang putih bersih, bayangan halus, serta tombol dengan warna biru khas.
  3. JavaScript (<script>): Mendengarkan kejadian (event) ketika tombol diklik, lalu mengubah teks, warna elemen, dan menampilkan pesan sambutan secara dinamis.

5. Kelebihan & Kekurangan Internal Scripting

Kelebihan:

  • Portabilitas: Hanya membutuhkan 1 file tunggal untuk dijalankan, sangat mudah dibagikan atau dites langsung di browser tanpa konfigurasi server lokal.
  • Mudah Dipelajari: Pemula tidak perlu bingung mengelola jalur file (file path) antar berbagai folder.

Kekurangan:

  • Skalabilitas: Jika kode bertambah panjang hingga ribuan baris, file akan menjadi sangat sulit dirawat (maintenance).
  • Caching: Browser tidak dapat menyimpan cache kode CSS/JS secara terpisah, sehingga performa kurang optimal untuk situs skala besar.
